🎯 Desafio: Estilizando o Formulário com Bootstrap 5

Sua missão é transformar este formulário "feio" e sem estilo em uma tela de cadastro moderna e responsiva usando apenas classes utilitárias e componentes do Bootstrap 5 (sem escrever CSS manual!).

📋 Instruções Passo a Passo:

  1. Importar o Bootstrap: Cole a tag <link> do CDN do Bootstrap 5.3 dentro do <head> do arquivo HTML.
  2. Centralizar a Página: No <body>, adicione as classes utilitárias para dar um fundo cinza claro e centralizar o cartão no meio da tela:
    • bg-light (Cor de fundo)
    • d-flex align-items-center justify-content-center min-vh-100 (Centralização com Flexbox)
  3. Estilizar o Cartão (Container do Formulário):
    • Adicione a classe card no contêiner do formulário.
    • Adicione espaçamento interno com p-4 e sombra com shadow-sm.
    • Limite a largura máxima com w-100 e o estilo style="max-width: 500px;".
  4. Estilizar os Campos do Formulário:
    • Adicione a classe mb-3 em cada <div> de grupo para separar os campos.
    • Aplique a classe form-label e negrito (fw-bold) em todos os elementos <label>.
    • Aplique a classe form-control em todos os elementos <input> (Nome, E-mail, Senha, Telefone e Data).
  5. Estilizar os Botões de Ação:
    • Coloque a classe d-flex gap-2 na <div> que envolve os dois botões para deixá-los lado a lado com um espaçamento entre eles.
    • Botão de Enviar: Adicione as classes btn btn-primary w-100.
    • Botão de Limpar: Adicione as classes btn btn-outline-secondary.
